# WDYM

Fish marketplace — customer PWA, vendor hub, admin, delivery and cleaning-unit apps. Live at [wdym.in](https://wdym.in) (Hostinger).

- Build scope for the first release: [docs/MVP-PRD.docx](docs/MVP-PRD.docx)
- Full product vision (18+ modules): [docs/PRD.docx](docs/PRD.docx)

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Deploy (Hostinger Node.js hosting)

Build command `npm run build`, start command `npm start`, Node 20+. Point `wdym.in` at the app in hPanel.
